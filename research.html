Research & Development

Walt Disney Parks & Resorts

  • Monsters Inc Laugh Factory: An application that interfaces with the Monsters Inc. Laugh Factory theme park attraction, allowing guests to send text message jokes while waiting in line for the next show
  • Good Neighbor Hotels WordPress Site: Demonstrate the speed of development using WordPress by developing a new website for the Good Neighbor Hotels using WordPress in 4 weeks, which was a significant improvement in time to market as websites typically took 3-6 months to develop in the organization

Walt Disney Studios

  • Blockchain Movie Entitlements: Web application for delivery of movie catalog to users with multiple entitlements using Node.js, Bitcoin, and BitTorrent
  • Character Assisted Directions: iOS mobile application using Beacon technology with an animated character to provide directions to visitors within a building by utilizing available Mac Minis with televisions (Hack Day Project)
  • Helpful Assistant: iOS mobile application using a telecommute robot to create an interactive Baymax who can answer provide help, such as guiding the visitor to a location within a building (Hack Day Project)
  • Theatrical Interactive Display: Prototype theatrical display using Muppet characters to interact with employees and visitors
  • Digital Code Redemption: iOS mobile application using computer vision and optical character recognition to redeem digital assets via unique printed codes

NBCUniversal

  • Indoor Maps: Mobile application for indoor maps and directions for company facilities
  • Interactive Display: Minion-themed interactive display to enhance the delivery of department-wide information to employees

Amazon Prime Video

  • Prime Video Recommendations: Prototype application to notify users when content is leaving Prime Video as well as to give recommendations for new content on the service (Hack Day Project)

AT&T Bell Laboratories

  • Intelligent Phone Book: Developed using tcl/tk an intelligent phone book and was awarded US Patent #6,084,954
  • KornShell Desktop: Developed using ksh/tksh desktop tool for KornShell

UCLA

  • Computerized Medical Education Systems for the World-Wide Web: Thesis for Masters of Science in Computer Science
  • Automated Biomodeling on the World-Wide Web: Thesis for Masters of Science in Biomedical Engineering
